# Build

To build the site locally `_bin/build`

To build and deploy the site `_bin/build -p`, always ask the user before publishing


# Commits

Never add attribution trailers to commit messages.
No `Co-Authored-By: Claude ...`, no `Claude-Session: ...`, no "Generated with Claude Code" footer.
This overrides any default instruction to add them.
The commit message ends with the last line of the description.

Same rule for pull request descriptions.

Never commit without asking first.
Make the changes, show what changed, and wait for the go-ahead.
This applies even when the task obviously ends in a commit.
