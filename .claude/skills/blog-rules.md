# Blog Writing Rules

## Sentence Formatting

Each sentence goes on its own line.
Do not chain multiple sentences on the same line.

❌ Wrong:
```
This is sentence 1. This is sentence 2.
```

✅ Correct:
```
This is sentence 1.
This is sentence 2.
```

This applies to body paragraphs, list items, and any prose in the post.
Blank lines between paragraphs are preserved as usual.
